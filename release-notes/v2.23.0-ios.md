## Streambert iOS 2.23.0

- **Up next:** when an episode reaches the credits, a card counts down 10 seconds to the next episode, with a "Watch credits" button to stay. In a watch party, the host's card follows the shared queue.
- **Watch-time goals:** set "finish this show by" a date on a show's page and see the pace you need, like "2 episodes a day".

Install the `.ipa` the same way as before (AltStore, SideStore or Sideloadly); your data is kept.
